# Проверка обработчика регистрации public

Из корня репозитория:

```powershell
dotnet run --project tests/PublicRegistrationRegression/PublicRegistrationRegression.csproj
```

Проверка вызывает обработчик настоящего Razor-компонента с подставными сервисами, без браузера, баз данных и отправки писем. Покрывает успешную регистрацию, отсутствие Support и организации, ошибку/исключение почтового сервиса, исключение регистрации, отказ регистрации, валидацию, несовпадение паролей и защиту от повторного нажатия во время обработки. Во всех завершённых сценариях проверяются сброс состояния ожидания и сохранение существующих заголовка и текста результата регистрации, в том числе при сбое уведомления.

Проверка не воспроизводит конкретный сбой на пользовательском сервере и не заменяет проверку формы в браузере.
